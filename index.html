Creator tools • Local processing

Long videos in.
Short clips out.

JudeClip AI is a desktop tool that helps creators find moments in long recordings, add subtitles, prepare captions and hashtags, and approve videos before sending them to TikTok's inbox for final posting.

Explore features

Runs on your computer. Video processing requires Python and FFmpeg. TikTok API access requires platform authorization.

Workflow

From recording to TikTok draft

1. Import

Choose a local video file or add supported video links you are authorized to use. Process multiple links in sequence.

2. Generate clips

Select clip duration and count. Make vertical videos with local automatic transcription and subtitles.

3. Review & approve

Preview the result, edit suggested captions and hashtags, and approve individual videos.

4. Send to TikTok

With an approved TikTok connection, upload a selected video to your TikTok inbox. Finish captioning and publishing inside TikTok.

Respect creator rights.

Upload only footage you own or have permission to edit and republish. Clip suggestions and captions need human review. TikTok API features depend on developer approval.

Privacy-conscious setup

This website is informational. It does not upload or process your video. The desktop app processes recordings locally; optional TikTok uploads transfer only clips you approve.
