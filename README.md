# JudeClip AI public website

A static informational website for the JudeClip AI desktop tool, deployed through GitHub Pages. Public URLs: /, /terms.html, /privacy.html.

## Important before TikTok review

The legal pages are explicitly marked as pre-release drafts. Add your verified legal operator identity, private contact address and legally required notice, and verify all statements before submitting the site to TikTok. A public website alone does not guarantee TikTok API approval, especially for apps intended only for personal use. Verify ownership of the URL prefix in TikTok for Developers.

This repo includes **website only**, no TikTok API secrets or OAuth tokens.
